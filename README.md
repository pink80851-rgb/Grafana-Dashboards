
這份 README 的設計重點在於：強調「為什麼要監控」以及「監控了什麼指標」。
📊 Enterprise Monitoring Dashboards (Grafana + Zabbix)這個儲存庫存放了我為企業環境開發的 Grafana 儀表板配置（JSON 格式）。
透過 Zabbix 7.0 採集底層數據，並在 Grafana 實現高度可視化的維運管理，旨在消除監控真空期並提升系統可觀測性 。

📁 監控分類與指標說明我將監控對象依設備屬性進行分類，並針對核心指標設計預警邏輯：
Print/ (HP M451dn)核心指標：
碳粉剩餘量（%）、總列印頁數追蹤、設備連線狀態。
價值：實現耗材自動化預警，避免人工巡檢導致的耗材中斷。

UPS/ (電力管理)核心指標：輸出負載百分比、電池健康狀態、輸入電壓波動。
價值：確保機房電力韌性，在異常發生時提供即時數據支持。

Server/ (基礎設施)核心指標：CPU/RAM 使用率、RAID 磁碟狀態、服務可用性監控。
價值：主動發現硬體潛在故障，維持業務連續性。

Switch/ (網路鏈路)核心指標：各 Port 流量（In/Out Traffic）、封包錯誤率、設備 Up/Down 狀態。
價值：透過網路拓樸與流量分析，快速定位鏈路瓶頸。

🛠️ 技術實踐亮點動態變數設計：面板整合 Grafana Variables 功能，實現單一儀表板即可切換監控不同樓層或區域的同類設備。
